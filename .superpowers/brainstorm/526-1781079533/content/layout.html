B. List + Edit dialog

Compact main list shows everything per row. Double-click or "Edit…" opens a small modal dialog to change one entry. Classic Windows pattern.

The "+ Add from running…" button (both layouts) opens a process picker: a list of running processes with their icon, name, and full path - you pick one and it pre-fills a new entry.
